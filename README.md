# דשבורד ניהול לידים חכם

דשבורד לניהול לידים לעסק קטן או בינוני, על נתוני דמה. כל ליד מקבל ציון בין 0 ל-100, והדשבורד מסמן לידים חדשים שלא קיבלו מענה תוך 24 שעות ולידים פתוחים שאין איתם קשר שבוע, ומציע לכל ליד את הפעולה הבאה.

הפרויקט נבנה עם Claude Code במסגרת שיעור 3 בקורס מטמיעי AI.

## צפייה

הדשבורד פועל באתר [1g0rh.github.io/leads-dashboard](https://1g0rh.github.io/leads-dashboard/) ב-GitHub Pages.

אפשר גם לפתוח את הקובץ `index.html` ישירות בדפדפן. אין ספריות חיצוניות ואין צורך בהתקנה.

## קבצים

| קובץ | תוכן |
|---|---|
| [SPEC.md](SPEC.md) | אפיון הפרויקט: מטרה, נתונים, לוגיקת הציון, המסך ובדיקת קבלה |
| [Practice.md](Practice.md) | הנחיות השמירה והעדכון ב-Git וב-GitHub |
| `index.html` | מבנה הדף |
| `styles.css` | עיצוב, מצב כהה ותצוגת מובייל |

| `data/mock-data.js` | יצירת נתוני הדמה |

כל השמות, העסקים ומספרי הטלפון בנתונים בדויים.
